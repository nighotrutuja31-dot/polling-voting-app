# 🗳️ PollVote - Polling & Voting App

A responsive web-based polling and voting application developed using HTML5, CSS3 and JavaScript.

This project was developed as part of the **VEDA Technology Web Development Internship – Day 23**.

---

## 📌 Project Overview

PollVote allows users to create polls with multiple options, vote on available polls and view the voting results in percentage format.

The application uses **Browser LocalStorage** to save poll data and voting status.

---

## ✨ Features

- Create multiple polls
- Add multiple voting options
- Interactive voting interface
- One vote per poll
- Duplicate vote prevention
- Live voting results
- Percentage calculation
- Visual percentage bars
- Multiple polls support
- LocalStorage data persistence
- Clear all polls option
- Input validation
- Responsive design
- Mobile-friendly interface

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Browser LocalStorage
